# XBarPlugins

Personal [xbar](https://github.com/matryer/xbar) plugins for the macOS menu bar.

| Plugin | What it does |
|--------|--------------|
| [septaPlugin](septaPlugin/) | Next SEPTA Regional Rail trains between two stations, with live delays |

## Using a plugin

1. Install [xbar](https://github.com/matryer/xbar#installation).
2. Copy the plugin script into your xbar plugins folder (xbar menu → *Open plugins folder…*) and make it executable (`chmod +x`).
3. Refresh xbar. Each plugin's folder has its own README with dependencies and settings.

Plugins follow the [xbar plugin guidelines](https://github.com/matryer/xbar-plugins/blob/main/CONTRIBUTING.md): one self-contained script per plugin, refresh rate in the filename, metadata in the header.
